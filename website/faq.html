Help & Answers

Frequently Asked Questions

Detailed answers on architecture, safety, troubleshooting, and configuring RaidR on Windows.

How does RaidR work without Android emulators like BlueStacks?

RaidR attaches directly to Google Play Games on PC using native Windows Win32 surface capture and OpenCV template matching + Tesseract 5 OCR. Because Google Play Games runs the official x86_64 PC build, there is zero Android VM overhead.

Does RaidR modify game files or read process memory?

No. RaidR operates strictly externally through visual pixel analysis and OS window messages. There is zero DLL injection, memory reading, binary patching, or packet manipulation, and all Python source code is open source on GitHub.

Can I cover or minimize Clash of Clans while farming?

Yes. Clicks and drags are dispatched directly to the game's CROSVM surface handle via Windows messages without hijacking your physical mouse cursor, so you can browse, watch videos, or work in other windows.

Why does Settings say my window aspect ratio isn't supported on 21:9 monitors?

UI templates are calibrated for 16:9 and 16:10 isometric framing. On ultrawide monitors, go to Settings → Switch display to 16:9, restart Clash of Clans so Google Play Games locks to 16:9, then click Restore my display.

Where are saved strategies, accounts, and settings stored?

All user profiles, custom deployment paths, custom troop crops, and multi-run account lists are stored locally under %LOCALAPPDATA%\RaidR\ and Windows user UI settings. Nothing is sent to external servers.

How can I inspect the source code or build RaidR myself?

Clone github.com/staticmooniq/RaidR, install dependencies from requirements-bot.txt, and run python main.py or bundle with pyinstaller RaidR.spec.
