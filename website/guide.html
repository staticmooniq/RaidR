Complete Setup & Strategy Guide

Follow these steps to configure Google Play Games PC, build custom troop deployment paths, enable dual-resource wall upgrades, and run safely in the background.

STEP 01 // REQUIREMENTS

Windows & Google Play Games PC Setup

  • Supported OS: Windows 10 or Windows 11 (64-bit). No Android emulator (BlueStacks, LDPlayer, Nox) needed.
  • Aspect Ratio: Google Play Games should render Clash of Clans in 16:9 or 16:10. If you use an ultrawide (21:9) monitor, open RaidR → Settings → Switch display to 16:9, restart Clash of Clans, then click Restore my display.
  • Bundled OCR Engine: Standalone builds from GitHub Releases include Tesseract 5 bundled directly — zero extra installs required.
STEP 02 // CUSTOM DEPLOYMENT DESIGNER

Drawing Custom Attack Paths

Open New Strategy or Edit Strategy on the Run tab and click Open Custom Deployment Designer:

  • Auto Zoom-Out Capture: Automatically sends camera zoom-out to match standard battlefield view and snaps 1:1 game pixels.
  • Line Drawing + Spacing Guard: Draw drag lines along base edges; RaidR samples randomized points along every line while strictly enforcing a configurable minimum pixel spacing so units never bunch up too close.
  • Randomized Timing & Sequence: Choose random human-like intervals (or fixed delay) plus randomized tap ordering on every battle.
  • Up to 7 Variations per Strategy: Save up to 7 independent deployment sets; RaidR randomly selects one set per raid for anti-pattern unpredictability.
STEP 03 // WALLS & AUTO UPGRADE

Dual-Resource Wall Dump & Loot Filters

  • Reserve Builders: Set Reserve builders = 1 in Settings to keep one builder dedicated to overflowing Gold and Elixir walls while Auto Upgrade uses remaining builders for structures.
  • Wall Threshold: Configure your Gold/Elixir dump threshold (e.g., 3M) and check frequency slider (every 1–15 battles) on the Run tab.
  • Loot Filtering: Set Minimum Gold, Minimum Elixir, optional Dark Elixir filtering, Max Next Skips, and Post-1-Star Loot Cleanup Delay under Settings → Matchmaking & Attack Settings.
STEP 04 // MULTI-ACCOUNT ROTATION

Multi-Run Farming Across Accounts

In Settings → Multi-Run Player Rotation, add your in-game Supercell ID account names in order. Toggle accounts between Run and Skip, set your per-account duration on the Run tab, and enable Multi-run. Everything auto-saves persistently across restarts.
