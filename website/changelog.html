RaidR Changelog

Full release notes, new automation features, and stability improvements for RaidR on Windows.

LATEST BUILD Nov 2026

Custom Deployment Designer & Persistent Auto-Save

  • Custom Deployment Designer: Draw deployment lines or click drop points directly on zoomed-out game pixels inside Strategy Designer. Enforces minimum spacing constraints, supports random or fixed delays, randomized point order, and up to 7 selectable sets per strategy.
  • Reliable Settings & Multi-Account Persistence: Fixed multi-run player loading across restarts and added automatic saving with atomic JSON writes across all Run & Settings controls.
  • Original Presets Preserved: Full Four-Edge Spam, Diamond Perimeter, Custom Deploy Zones, and Single Corner presets remain built-in and selectable.
v1.2 2026-11-11

Universal Depleted Filter & Dual-Resource Walls

  • Universal Depleted Card Filter: Color-divergence detection ignores exhausted x0 troop, spell, and hero cards during deployment.
  • Hero Ability Timing: Per-hero timing options (Random 5–12s, Custom seconds, or Never) in the visual Strategy Editor.
  • Builder Base Improvements: Dual-resource wall upgrades (Gold + Elixir), automated Loot Cart collection, 4-second Build button detection, and clean single-tap camp deploys.
v1.1 2026-11-10

Strict Background Window Isolation & Game Launcher

  • Hardened Win32 surface input routing so browsing or multitasking never triggers cursor jumps or stray scroll events.
  • Added non-stealing background capture (SW_SHOWNOACTIVATE) and integrated one-click Launch Game via Google Play Games PC.
  • Introduced text-only wall action matching across Level 8+ walls and both 16:9 and 16:10 aspect ratios.
v1.0.x 2026-10-26 – 11-06

Initial Research Release & Auto-Updater

  • OCR matchmaking filters (Gold, Elixir, optional Dark Elixir), skip caps, and post-1-star cleanup timer.
  • Bundled Tesseract 5 OCR engine, Windows taskbar thumbnail controls, and in-app GitHub release auto-updater.
